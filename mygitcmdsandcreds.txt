After making changes to file, the following commands are necessary
Command to add changed files: git add .
command to commit files to local repo with a message regarding changes made: git commit -m <messages go here in single quotes>
then u can go to command to push local repo to remote github origin
On github, create a pull request for the new branch (if any) 



Command to link our local repo to a remote origin ( a repo visually created on GitHub)
git remote add origin https://github.com/zele9/mastering_git.git <link is GitHub origin http link which serves as origin for command>

Command to push locally committed files to GitHub origin
git push -u origin main (branch name where changes were made. this automatically creates a new branch in the remote github repo with the same local branch name)

command to push new commits to remot repo to a specific branch: git push --set-upstream origin second-branch / alternatively use git push -u origin <branch-name>
command to see all branches, local and remote, git branch -a and -r to see only remote branches
command to delete a local branch: git branch -d <branch_name>
command to only create a new branch in my local repo: git branch <branch name>
command to switch to another branch: git checkout <branch name>
command to create and auto switch to new branch in local repo: git checkout -b <branch name>

command to go back to a certain commit and stage all changes after that commit: git reset --soft <commit-hash> called a soft reset
command to go back to a certain commit and leave all changes after that commit in working directory and not staged: git reset <commit-hash> called a mixed reset
command to go back to a certain commit and delete all changes after that commit: git reset --hard <commit-hash> called a hard reset

Always find git hash by running: git log and it appears like this “commit 8e63d1a91f837925fe6b048399b81886f25eaef1”

To go back to a specific commit without covering your tracks use: git revert <commit-hash>
A merge conflict would appear, resolve it manually, git add the changes and the use: git revert —continue to finish command process.
You’ll be in a vi editor where you’ll enter “:qa!” To save and exit after putting a commit message if any.

When you’re working on something and another urgent thing comes up and you want to keep yours, use: git stash
Go do the urgent thing, when you come back u can use git stash list to see list of stashes, copy the stash number you want (e.g stash@{0}) and use git stash apply <stash number>
